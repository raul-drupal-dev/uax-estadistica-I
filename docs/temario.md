| :----------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------- | :----------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :------------------------------------------------- |
| **Escala Nominal**                         | • Datos categóricos sin orden natural.<br>• Solo permite contar frecuencias y moda.<br>• IA: Se usa _One-hot encoding_.                                     | N/A                                                    | No permite sumas ni promedios.                                                                                                                                                                                                                    | Color de ojos o etiquetas "Spam/No Spam".          |

| **Dato Cualitativo** ⭐                    | • Describe cualidades o categorías.                                                                                                                         | N/A                                                    | No permite operaciones aritméticas directas.                                                                                                                                                                                                      | Color de ojos, género, tipo de dispositivo.        |
| **Dato Cuantitativo** ⭐                   | • Valor numérico con significado de magnitud.                                                                                                               | N/A                                                    | Permite sumas, restas y medidas de dispersión.                                                                                                                                                                                                    | Altura, peso, tiempo de ejecución.                 |
| **Media ($\bar{x}$)** ⭐                   | • Centro de gravedad o valor promedio.<br>• Coincide con el **momento de 1er orden** respecto al origen.                                                    | $\bar{x} = \frac{\sum x_i}{n}$                         | Muy sensible a **outliers** (no es robusta).                                                                                                                                                                                                      | Nota media de un examen.                           |
| **Media Geométrica ($G$)** ⭐              | • Promedio multiplicativo útil para tasas/ratios.                                                                                                           | $G = \sqrt[n]{\prod_{i=1}^{n} x_i}$                    | Requiere valores positivos.                                                                                                                                                                                                                       | Crecimiento medio anual.                           |
| **Media Armónica ($H$)** ⭐                | • Promedio para razones/velocidades.                                                                                                                        | $H = \frac{n}{\sum_{i=1}^{n} (1/x_i)}$                 | Útil cuando promediamos tasas.                                                                                                                                                                                                                    | Velocidad media en tramos.                         |

| **Moda** ⭐                                | • Valor o categoría más frecuente.                                                                                                                          | N/A                                                    | Útil en variables cualitativas.                                                                                                                                                                                                                   | Talla más vendida (M).                             |
| **Cuartil 1 ($Q_1$)** ⭐                   | • Divide el 25% inferior de los datos ordenados.<br>• Es el **percentil 25**.                                                                               | Posición: $\frac{n+1}{4}$                              | Robusto ante outliers. Se usa en el **IQR**.                                                                                                                                                                                                      | Corte inferior en un boxplot.                      |
| **Cuartil 3 ($Q_3$)** ⭐                   | • Divide el 75% inferior (o 25% superior) de los datos ordenados.<br>• Es el **percentil 75**.                                                              | Posición: $\frac{3(n+1)}{4}$                           | Robusto ante outliers. Se usa en el **IQR**.                                                                                                                                                                                                      | Corte superior en un boxplot.                      |
| **Varianza ($S^2$)** ⭐                    | • Mide la dispersión respecto a la media.<br>• Unidades siempre al cuadrado.<br>• IA: Mide sensibilidad a fluctuaciones.                                    | $S^2 = \frac{\sum (x_i - \bar{x})^2}{n-1}$             | Se usa $n-1$ (**Bessel**) para que sea insesgada. Siempre es $\ge 0$.                                                                                                                                                                             | Variabilidad en la latencia de un servidor.        |
| **Desv. Típica ($S$)** ⭐                  | • Raíz de la varianza; dispersión en las mismas unidades.                                                                                                   | $S = \sqrt{S^2}$                                       | Más interpretable que la varianza.                                                                                                                                                                                                                | Desviación en tiempos de respuesta.                |
| **IQR (Rango Inter.)** ⭐                  | • Dispersión del **50% central** de los datos.<br>• Es la base para dibujar los Boxplots.                                                                   | $IQR = Q_3 - Q_1$                                      | Robusto ante outliers. Si es grande, indica mucha variabilidad central.                                                                                                                                                                           | Longitud de la caja en un boxplot.                 |
| **Coef. Variación ($CV$)**                 | • Dispersión **relativa** (%) respecto a la media.<br>• Es adimensional (permite comparar grupos distintos).                                                | $CV = \frac{s}{\bar{x}} \cdot 100$                     | Útil para comparar variables con diferentes unidades o medias.                                                                                                                                                                                    | Comparar estabilidad de dos algoritmos de ML.      |
| **Exploración de Datos (EDA)**             | • Inspección inicial para entender patrones y anomalías.                                                                                                    | N/A                                                    | Usa visualizaciones y resúmenes.                                                                                                                                                                                                                  | Histogramas, boxplots, scatter plots.              |
| **Limpieza de Datos**                      | • Detecta y corrige faltantes, duplicados o incoherencias.                                                                                                  | N/A                                                    | Mejora la calidad antes del análisis.                                                                                                                                                                                                             | Imputar con media/mediana.                         |
| **Muestra Representativa**                 | • Muestra que refleja la población objetivo.                                                                                                                | N/A                                                    | Reduce sesgos de muestreo.                                                                                                                                                                                                                        | Muestreo aleatorio estratificado.                  |
| **Covarianza ($S_{xy}$)** ⭐               | • Mide la variación conjunta entre $X$ e $Y$.<br>• Si es $>0$, relación directa; si es $<0$, relación inversa; si es $=0$, **no hay relación lineal**.      | $S_{xy} = \frac{\sum (x_i-\bar{x})(y_i-\bar{y})}{n-1}$ | Puede ser **positiva, negativa o cero**. **No está acotada** (depende de la escala/unidades); por eso se estandariza con $r$. Si $S_{xy}=0$, cambios en $X$ **no implican** cambios proporcionales en $Y$; podría existir relación **no lineal**. | Co-movimiento entre horas de estudio y nota.       |
| **Coef. Correlación ($r$)** ⭐             | • Fuerza y dirección de relación **lineal**.<br>• Acotado entre -1 y 1.<br>• IA: Útil en selección de variables (EDA).                                      | $r = \frac{S_{xy}}{S_x S_y}$                           | Rango: $-1 \le r \le 1$. **Correlación no implica causalidad**. No detecta relaciones no lineales.                                                                                                                                                | $r=0.96$ entre horas estudio y nota (muy fuerte).  |
| **Regresión Lineal Simple** ⭐             | • Modelo lineal que relaciona $X$ con $Y$.                                                                                                                  | $\hat{y}=\alpha+\beta x$                               | Asume linealidad, independencia y homocedasticidad.                                                                                                                                                                                               | Predicción de nota según horas de estudio.         |
| **Método de Mínimos Cuadrados**            | • Estima $\alpha$ y $\beta$ minimizando errores al cuadrado.                                                                                                | N/A                                                    | Base del ajuste lineal.                                                                                                                                                                                                                           | Ajuste de recta a datos.                           |
| **Pendiente ($\beta$ o $b$)**              | • Cambio esperado en $Y$ por unidad de $X$.                                                                                                                 | $b = \frac{S_{xy}}{S_x^2}$                             | Signo indica dirección de la relación.                                                                                                                                                                                                            | $b=2.3$ puntos por hora.                           |
| **Ordenada en el Origen ($\alpha$ o $a$)** | • Valor de $Y$ cuando $X=0$.                                                                                                                                | N/A                                                    | Intersección con el eje $Y$.                                                                                                                                                                                                                      | $a=43.58$ en el ejemplo.                           |
| **Supuestos del Modelo Lineal** ⭐         | • Linealidad, independencia, homocedasticidad y normalidad de residuos.                                                                                     | N/A                                                    | Validar con análisis de residuos.                                                                                                                                                                                                                 | Comprobar residuos vs. predicciones.               |
| **Coef. Determ. ($R^2$)** ⭐               | • % de variabilidad de $Y$ explicada por el modelo.<br>• Mide la calidad del ajuste de la regresión.                                                        | $R^2 = r^2$                                            | Varía de 0 a 1. Valores altos indican predicciones fiables.                                                                                                                                                                                       | $R^2=0.92$: El 92% de la nota depende del estudio. |

### Tabla de Repaso: Probabilidad y Distribuciones (U3 y U4) ⭐

| Término                            | Lista de Definición (Puntos Clave)                                                                                                                                  | Lista de Fórmulas                                                         | Consideraciones Importantes                                                                            | Ejemplo                                                  |
| :--------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :------------------------------------------------------------------------ | :----------------------------------------------------------------------------------------------------- | :------------------------------------------------------- |
| **Variable Aleatoria ($X$)**       | • Función que asigna valores numéricos a resultados aleatorios.<br>• **Discreta**: Valores contables (con PMF).<br>• **Continua**: Valores en intervalos (con PDF). | $X: \Omega \rightarrow \mathbb{R}$                                        | La probabilidad puntual en continuas es siempre **cero**: $P(X=x) = 0$.                                | $X$: nº de iteraciones hasta converger.                  |
| **Espacio Muestral ($\Omega$)** ⭐ | • Conjunto de todos los resultados posibles.                                                                                                                        | N/A                                                                       | Base para definir eventos y probabilidades.                                                            | Dado: $\{1,2,3,4,5,6\}$.                                 |
| **Probabilidad ($P(A)$)** ⭐       | • Medida del grado de incertidumbre de un evento $A$.                                                                                                               | $P(A)$                                                                    | $0 \le P(A) \le 1$.                                                                                    | $P(\text{lluvia})=0.7$.                                  |
| **CDF ($F(x)$)**                   | • Probabilidad acumulada hasta $x$.<br>• Siempre monótona no decreciente.<br>• Va de 0 a 1.                                                                         | $F(x) = P(X \le x)$                                                       | $P(a < X \le b) = F(b) - F(a)$. Es clave para calcular percentiles.                                    | ¿Probabilidad de que el modelo tarde $\le 5$h?           |
| **PMF ($p_X(x)$)** ⭐              | • Función de masa para V.A. **discreta**.<br>• Da la probabilidad exacta de cada valor.                                                                             | $p_X(x) = P(X=x)$                                                         | $\sum_x p_X(x) = 1$. Se relaciona con la CDF: $F(x)=\sum_{t\le x} p_X(t)$.                             | Probabilidad de 3 éxitos en 10 ensayos.                  |
| **PDF ($f_X(x)$)** ⭐              | • Función de densidad para V.A. **continua**.<br>• Probabilidades como áreas bajo la curva.                                                                         | $P(a<X\le b)=\int_a^b f_X(x)\,dx$                                         | $f_X(x) \ge 0$ y $\int_{-\infty}^{\infty} f_X(x)\,dx=1$. Relación: $F(x)=\int_{-\infty}^x f_X(t)\,dt$. | Área entre 2 y 4 en una normal.                          |
| **Esperanza ($E[X]$)** ⭐          | • Valor promedio a largo plazo (centro de gravedad).<br>• Es un **operador lineal**.                                                                                | $E[aX+b] = aE[X]+b$                                                       | $E[X]$ de una constante es la constante. No requiere independencia para sumas.                         | Esperanza de un dado = 3.5.                              |
| **Varianza ($Var(X)$)** ⭐         | • Mide la dispersión o sensibilidad ante fluctuaciones.<br>• Siempre es $\ge 0$.                                                                                    | $Var(X) = E[X^2] - (E[X])^2$                                              | $Var(aX+b) = a^2 Var(X)$. Si son **independientes**, la varianza de la suma es la suma de varianzas.   | Variabilidad en el error de predicción.                  |
| **Softmax**                        | • Convierte un vector de salida en una distribución de probabilidad.<br>• La suma de todas las salidas es 1.                                                        | $P_i = \frac{e^{z_i}}{\sum e^{z_k}}$                                      | Fundamental en redes neuronales para clasiﬁcación multiclase.                                          | Probabilidades: [0.7 Gato, 0.2 Perro, 0.1 Otro].         |
| **Bernoulli / Binomial** ⭐        | • Bernoulli: Un único ensayo (1 éxito, 0 fracaso).<br>• Binomial: Suma de $n$ Bernoullis **independientes**.                                                        | $E[X] = np$<br>$Var(X) = np(1-p)$                                         | Asume probabilidad $p$ constante en todos los ensayos.                                                 | nº de correos SPAM en un lote de 100.                    |
| **Poisson ($\lambda$)** ⭐         | • Eventos raros en un intervalo de tiempo/espacio.<br>• Tasa media $\lambda$ es constante.                                                                          | $P(X=k) = \frac{\lambda^k e^{-\lambda}}{k!}$<br>$E[X] = Var(X) = \lambda$ | **Aproximación**: Si $n \ge 30$ y $p \le 0.1$, la Binomial se parece a la Poisson con $\lambda = np$.  | nº de peticiones a un servidor por segundo.              |
| **Exponencial ($\lambda$)**        | • Tiempo de espera entre eventos de Poisson.<br>• Posee **Falta de Memoria**.                                                                                       | $E[X] = 1/\lambda$<br>$Var(X) = 1/\lambda^2$                              | La falta de memoria implica que el tiempo ya pasado no afecta al futuro.                               | Tiempo hasta que un componente hardware falla.           |
| **Normal $N(\mu, \sigma^2)$** ⭐   | • Campana de Gauss simétrica.<br>• Media, mediana y moda coinciden en $\mu$.                                                                                        | $Z = \frac{X-\mu}{\sigma} \sim N(0,1)$                                    | **Regla Empírica**: 68% datos en $\pm 1\sigma$, 95% en $\pm 2\sigma$, 99.7% en $\pm 3\sigma$.          | Inicialización de pesos en una red neuronal.             |
| **Chi-cuadrado ($\chi^2$)** ⭐     | • Distribución de la suma de cuadrados de normales estándar.<br>• Solo valores positivos; asimétrica a la derecha.                                                  | $\chi^2 = \sum_{i=1}^k Z_i^2$                                             | Depende de $k$ grados de libertad. Se usa en pruebas de varianza y bondad de ajuste.                   | Test de varianza en un proceso.                          |
| **t de Student** ⭐                | • Para medias con $\sigma$ desconocida.<br>• Colas más pesadas que la normal.                                                                                       | $T = \frac{\bar{X}-\mu_0}{S/\sqrt{n}}$                                    | Depende de $n-1$ g.l.; se aproxima a normal al crecer $n$.                                             | Comparar media muestral con $\mu_0$.                     |
| **F de Snedecor** ⭐               | • Cociente de dos varianzas independientes escaladas.<br>• Solo valores positivos; asimétrica.                                                                      | $F = \frac{S_1^2}{S_2^2}$                                                 | Depende de $(n_1-1, n_2-1)$ g.l. Se usa en contrastes de varianzas y ANOVA.                            | Comparar varianzas de dos grupos.                        |
| **Teorema C. Límite** ⭐           | • La media de una muestra grande ($n \ge 30$) siempre tiende a ser Normal.                                                                                          | $\bar{X} \approx N(\mu, \frac{\sigma^2}{n})$                              | Funciona incluso si la distribución original **no** es normal.                                         | El promedio de errores de muchos experimentos.           |
| **Corr. Continuidad**              | • Ajuste de $\pm 0.5$ al usar la Normal para calcular probabilidades de variables discretas.                                                                        | $P(X=k) \approx P(k-0.5 < X < k+0.5)$                                     | Se usa cuando aproximamos Binomial o Poisson mediante una Normal.                                      | Calcular $P(X \le 10)$ en una Binomial usando la Normal. |

### Tabla de Repaso: Inferencia y Contrastes de Hipótesis (U5 y U6) ⭐

| Término                                  | Lista de Definición (Puntos Clave)                                                                                        | Lista de Fórmulas                                           | Consideraciones Importantes                                                         | Ejemplo                                                            |
| :--------------------------------------- | :------------------------------------------------------------------------------------------------------------------------ | :---------------------------------------------------------- | :---------------------------------------------------------------------------------- | :----------------------------------------------------------------- |
| **Estimador Insesgado** ⭐               | • Su valor esperado coincide con el parámetro real.<br>• En promedio, "acierta" al valor poblacional.                     | $E[\hat{\theta}] = \theta$                                  | La varianza muestral $S^2$ usa $n-1$ para ser insesgada.                            | La media muestral $\bar{x}$ estima a $\mu$.                        |
| **Estimación Puntual** ⭐                | • Valor único como estimación de un parámetro.                                                                            | $\hat{\theta}$                                              | Depende de la muestra; puede ser sesgada o insesgada.                               | $\bar{x}$ como estimador de $\mu$.                                 |
| **Intervalo de Confianza (aprox.)** ⭐   | • Rango plausible para un parámetro con un nivel de confianza.                                                            | $\hat{\theta} \pm z\,\mathrm{se}(\hat{\theta})$             | Se interpreta en términos de repetición muestral.                                   | IC 95% para la media.                                              |
| **Hipótesis ($H_0$ vs $H_1$)** ⭐        | • $H_0$: Asumida cierta por defecto ("no hay cambio").<br>• $H_1$: Lo que se quiere demostrar.                            | Bilateral: $\mu \neq \mu_0$<br>Unilateral: $\mu > \mu_0$    | Nunca se "acepta" $H_0$, solo "no se rechaza".                                      | $H_0$: El modelo A y B tienen igual precisión.                     |
| **Error Tipo I ($\alpha$)** ⭐           | • Rechazar $H_0$ siendo esta verdadera.<br>• Conocido como **Falso Positivo**.                                            | $P(\text{Rechazar } H_0 \mid H_0 \text{ es } V)$            | Se controla fijando el nivel de significación (0.05 o 0.01).                        | Decir que un modelo es mejor cuando no lo es.                      |
| **Error Tipo II ($\beta$)** ⭐           | • No rechazar $H_0$ siendo esta falsa.<br>• Conocido como **Falso Negativo**.                                             | **Potencia** = $1 - \beta$                                  | La potencia mide la capacidad de detectar mejoras reales.                           | No detectar que un modelo es realmente superior.                   |
| **Nivel de Significación ($\alpha$)** ⭐ | • Máxima probabilidad de Error Tipo I tolerada.                                                                           | N/A                                                         | Típico: $\alpha=0.05$ o $0.01$.                                                     | Fijar $\alpha=0.05$ en un contraste.                               |
| **p-valor** ⭐                           | • Probabilidad de obtener un resultado tan extremo como el observado bajo $H_0$.                                          | Si $p \text{-valor} < \alpha \implies$ Rechazar $H_0$       | Mide la compatibilidad entre datos y $H_0$; no es la prob. de que $H_0$ sea cierta. | $p=0.03$ es significativo para $\alpha=0.05$, pero no para $0.01$. |
| **Contraste Z (Media)**                  | • Se usa con $\sigma$ conocida o muestra grande ($n \ge 30$).                                                             | $Z = \frac{\bar{X} - \mu_0}{\sigma / \sqrt{n}} \sim N(0,1)$ | Si $n$ es grande, el TCL permite usarlo aunque la población no sea Normal.          | Probar si la precisión media es distinta de 0.85.                  |
| **Contraste t-Student** ⭐               | • Se usa con $\sigma$ **desconocida** y muestra pequeña.<br>• Distribución simétrica con colas más pesadas que la Normal. | $t = \frac{\bar{X} - \mu_0}{S / \sqrt{n}} \sim t_{n-1}$     | Se pierde un grado de libertad al estimar la media con $S$.                         | Comparar el tiempo de ejecución de un nuevo algoritmo ($n=15$).    |
| **Contraste $\chi^2$ (Varianza)**        | • Prueba si la varianza poblacional es igual a un valor.<br>• Distribución asimétrica positiva ($>0$).                    | $\chi^2 = \frac{(n-1)S^2}{\sigma_0^2} \sim \chi^2_{n-1}$    | Base para intervalos de confianza de variabilidad.                                  | Validar si el error de un modelo tiene $\sigma^2 \le 0.04$.        |
| **Test Bondad Ajuste ($\chi^2$)** ⭐     | • Evalúa si los datos siguen una distribución teórica.                                                                    | $\sum \frac{(O_i - E_i)^2}{E_i}$                            | Requiere que las frecuencias esperadas ($E_i$) sean $\ge 5$.                        | ¿Un generador de números aleatorios es realmente Uniforme?.        |
| **Test Kolm.-Smirnov (KS)** ⭐           | • Compara la función de distribución (CDF) empírica vs teórica.                                                           | $D = \sup \lvert F_n(x) - F_0(x) \rvert$                    | Sensible a diferencias en cualquier parte de la distribución (centro y colas).      | Contrastar si una muestra proviene de una Normal específica.       |
| **Contraste F (Snedecor)**               | • Compara las varianzas de dos poblaciones normales.                                                                      | $F = \frac{S_1^2}{S_2^2} \sim F_{n_1-1, n_2-1}$             | Siempre se pone la varianza mayor en el numerador.                                  | Evaluar si dos implementaciones de IA tienen la misma estabilidad. |
